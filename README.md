# Gerenciador de Estoque — C#

Sistema de gerenciamento de estoque desenvolvido em **C# e .NET Framework**, com o objetivo de aplicar conhecimentos de lógica de programação, Programação Orientada a Objetos (POO) e manipulação de dados.

O projeto permite cadastrar, consultar e atualizar produtos por meio de uma interface de console.

---

## Funcionalidades

- Cadastro de produtos com nome, quantidade e preço.
- Listagem de todos os produtos cadastrados.
- Pesquisa de produtos pelo nome, sem diferenciação entre letras maiúsculas e minúsculas.
- Adição e retirada de unidades do estoque.
- Validação de quantidades para evitar movimentações inválidas.
- Cálculo do valor total dos produtos armazenados.

## Como Executar

1. Clone o repositório:

   `git clone https://github.com/GuilhermeGobbatoDev/gerenciador-estoque-csharp.git`

2. Abra a solução `Gerenciador_Produtos.slnx` no Visual Studio.
3. Compile e execute a aplicação.
4. Utilize o menu interativo do console para acessar as funcionalidades.

---

## Limitações e Melhorias Futuras

Atualmente, os produtos são armazenados temporariamente em memória, utilizando listas. Portanto, os dados são perdidos quando a aplicação é encerrada.

O projeto poderá receber melhorias como:

- Persistência de dados em banco de dados.
- Separação de responsabilidades em diferentes classes.
- Aprimoramento das validações de entrada.
- Implementação de novas funcionalidades de gerenciamento.
